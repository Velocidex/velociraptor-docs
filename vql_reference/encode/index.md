# Encode/Decode

Encoder, decoders and cryptographic functions.
|Plugin/Function|Type|Description|
|-|-|-|
|[base64decode](base64decode)|Function|Decodes a base64 encoded string|
|[base64encode](base64encode)|Function|Encodes a string into base64|
|[base85decode](base85decode)|Function|Decode a base85 encoded string|
|[compress](compress)|Function|Compress a file using GZip|
|[crypto_rc4](crypto_rc4)|Function|Apply rc4 to the string and key|
|[encode](encode)|Function|Encode an object as a string|
|[entropy](entropy)|Function|Calculates shannon scale entropy of a string|
|[gunzip](gunzip)|Function|Uncompress a gzip-compressed block of data|
|[hash](hash)|Function|Calculate the hash of a file|
|[lzxpress_decompress](lzxpress_decompress)|Function|Decompress an lzxpress blob|
|[pk_decrypt](pk_decrypt)|Function|Decrypt files using pubkey encryption|
|[pk_encrypt](pk_encrypt)|Function|Encrypt files using pubkey encryption|
|[rot13](rot13)|Function|Apply rot13 deobfuscation to the string|
|[tlsh_hash](tlsh_hash)|Function|Calculate the tlsh hash of a file|
|[unhex](unhex)|Function|Apply hex decoding to the string|
|[utf16](utf16)|Function|Parse input from utf16|
|[utf16_encode](utf16_encode)|Function|Encode a string to utf16 bytes|
|[xor](xor)|Function|Apply xor to the string and key|
